# Changelog

All notable CyberFlix changes are documented here.

The project follows Semantic Versioning from the new baseline starting at `0.0.1`.

## [0.0.2] - 2026-09-02

### Added
- New cinematic streaming-service design language across the full skin.
- User-defined CyberFlix palette based on Stormy Teal, Vibrant Coral, Intense Cherry, Sunflower Gold, Shadow Grey, Platinum, Eggshell and Light Bronze.
- Floating/glass navigation treatment with stronger active-state hierarchy.
- Reworked home shelves, section typography and Continue Watching emphasis.
- Dedicated cinematic hover overlay with streaming-style primary and secondary actions.
- Expanded detail-page backdrop treatment, metadata, action buttons and typography.
- Full visual passes for library, search, login, dialogs, drawer, settings, player OSD, feedback, responsive layouts and accessibility.

### Changed
- Moved the visual identity away from the earlier neon-heavy prototype toward a premium dark cinema aesthetic.
- Stormy Teal is now the primary interaction accent; Coral/Cherry provide focus and featured accents; Gold/Bronze are intentionally rare premium accents.
- Card artwork remains owned by Jellyfin; CyberFlix only styles containers, overlays and presentation.

## [0.0.1] - 2026-09-02

### Added
- Formal CyberFlix project structure and version metadata.
- Archived the former CSS prototype under `prototype/v1.1.0/`.
- Central design-token system.
- Foundation styling for background, header, home, cards, overlay and detail pages.
- Initial library, search, login, player, settings and feedback modules.
- Responsive and accessibility layers.
- Build and validation scripts.
- Development, architecture and release documentation.

### Changed
- Reset public development versioning to `0.0.1`.
- Separated card presentation from hover-overlay styling to prevent image regressions.
