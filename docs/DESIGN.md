# CyberFlix Design System

CyberFlix 0.0.2 moves away from a themed Jellyfin dashboard and toward a dedicated cinema-first streaming interface.

## Palette roles

- **Black / Shadow Grey** — primary cinema surfaces and depth.
- **Stormy Teal (`#0F7173`)** — primary interaction, navigation, focus and selected state.
- **Vibrant Coral (`#F05D5E`) / Intense Cherry (`#AD343E`)** — featured content, progress and high-energy emphasis.
- **Platinum (`#E7ECEF`) / Eggshell (`#E0E0CE`)** — text and familiar bright playback actions.
- **Sunflower Gold (`#F2AF29`) / Light Bronze (`#D8A47F`)** — rare premium/status accents; never used as the dominant UI color.
- **Iron Grey (`#474747`)** — neutral controls and scrollbar surfaces.

## Principles

1. Content artwork dominates; navigation and chrome recede.
2. Use blur and translucent panels only where they add hierarchy.
3. Keep motion short and deliberate; cards lift as one unit.
4. Never overwrite Jellyfin card `background-image` values.
5. Primary playback remains immediately recognizable through a bright high-contrast action.
6. Accent colors communicate state, not decoration everywhere.
7. Desktop should feel cinematic; mobile should remain calm and compact.
